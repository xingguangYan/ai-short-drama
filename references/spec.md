# 成片验收规格（对标片分析）

## 对标片

`40359102044-1-16.mp4`（867s / 640×360 / 30fps）：公路求生题材竖屏短剧，平均镜头 11.2 秒，14 处黑场转场（竖屏短剧的节奏基准），人物始终在场（暗调小构图），mean -20.2dB / max 0dB / EBU I = -17.5 LUFS，对白段平均 6 秒。**此文件是模板，勿删。**

## 成片规格（本流水线）

| 项 | 规格 |
|---|---|
| 分辨率 | 1088×1920 竖屏 |
| 帧率 | 24fps |
| 每集镜头 | 一场一镜，镜长 = 该场台词总时长 + 2.5s（约 5-12 秒） |
| 音轨 | 单轨：**镜头自带人物语音**（H3 生成、口型同步） |
| 禁止 | TTS 叠加、底部字幕、旁白叠加、黑场转场 |
| 转场 | 硬切 |
| 响度 | 逐镜按 EBU I 归一到 -17.5 LUFS（增益限 ±8dB），alimiter 0.97 |
| 编码 | H.264 crf18/20 + AAC 192k mono 44100 |

## 验收清单（每集）

1. 时长 = 各镜 `frames/24` 之和（ffprobe 核对）。
2. 音视频流各一、时长对齐（镜内 a≈v）。
3. 响度抽检 `ebur128` I ≈ -17.5 LUFS ±2。
4. 无 TTS 残留：成片音轨必须与某镜自带音轨同源（装配只做音量归一，不混入新声）。
5. 无字幕：装配脚本不烧字幕即过。
6. 语音内容抽查：转写各镜，关键台词应在；漏句先评估是否影响剧情再决定重渲染。

## 已知质量边界

- H3 语音可能漏句（如 EP01 漏"七十二小时"）、缩词（"防潮布"→"房"）。这是模型生成水平，不是装配 bug。
- 暗调画面会被 blackdetect 误报全黑，正常。
